## 本轮服务端状态的约束

业务元数据已不再以 localStorage 为主存储；浏览器旧资料不会自动混入已登录租户，可通过“迁移当前地区的本地演示资料”显式迁移。旧记录不会删除。新二进制已迁入服务端文件目录；旧 IndexedDB 文件可逐项显式上传。未迁移的旧文件仍只能在原浏览器读取。文件卷必须与数据库成套备份；当前单 API 实例的应用锁用于串行业务引用写入与删除。

演示入口每个会话分配独立演示租户，不等于多个浏览器共享同一个演示工作区；需要跨浏览器共享业务时使用管理员配置的真实账号及相同租户。会话存于服务器，Cookie 为 HttpOnly/SameSite=Strict；8 小时到期。改密码、禁用或移除账号后旧会话不再有效。

管理员、操作员、只读用户的实际服务端角色分别是 admin/editor/viewer，场景范围由服务器账号配置确定。页面“演示用户/角色”表仍是业务演示配置，不会改变登录身份的真实权限。

所有已知缺口仍保留；本轮结果不代表完成总体技术方案或生产部署验收。生产启动保护继续启用。

## 0.3.0 采集与查询状态

Mock 观测可通过真实队列执行、写入 PostgreSQL/PostGIS 并经授权 API 查询；不再将 Worker 与查询视为互不相连的演示。默认固定演示模式；管理员显式切入库模式后不做自动回退。

开发 API 内嵌执行器只用于单进程文件模式；独立 Worker 必须使用 PostgreSQL。水位线是最新成功小时，不是全时段完整性保证；补数任务进度显示已提交小时。天擎可暂缓接入，后续接入时仍须核对鉴权、分页、单位、质量码和现场网络。
