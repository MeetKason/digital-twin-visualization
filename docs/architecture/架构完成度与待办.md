## 本轮服务端状态的约束

Web 端状态读取按任务状态动态轮询：地图空闲30秒、任务运行5秒；采集管理空闲状态30秒、运行中3秒；健康摘要60秒。后台标签页暂停请求，切回时立即刷新，避免无任务时高频重复查询。

业务元数据已不再以 localStorage 为主存储；浏览器旧资料不会自动混入已登录租户，可通过“迁移当前地区的本地演示资料”显式迁移。旧记录不会删除。新二进制已迁入服务端文件目录；旧 IndexedDB 文件可逐项显式上传。未迁移的旧文件仍只能在原浏览器读取。文件卷必须与数据库成套备份；当前单 API 实例的应用锁用于串行业务引用写入与删除。

演示入口每个会话分配独立演示租户，不等于多个浏览器共享同一个演示工作区；需要跨浏览器共享业务时使用管理员配置的真实账号及相同租户。会话存于服务器，Cookie 为 HttpOnly/SameSite=Strict；8 小时到期。改密码、禁用或移除账号后旧会话不再有效。

管理员、操作员、只读用户的实际服务端角色分别是 admin/editor/viewer，场景范围由服务器账号配置确定。登录账号管理只允许真实管理员访问；业务演示用户数据不作为身份或授权来源。

所有已知缺口仍保留；本轮结果不代表完成总体技术方案或生产部署验收。生产启动保护继续启用。当前可部署为服务器上的 Mock/演示实例；正式生产模式尚不可启用。建议先创建管理员账号、关闭演示登录，并经 TLS 反向代理访问。目标机原生架构、网络隔离和权限仍需现场验收。

## 产品级采集与查询状态

已注册天气产品均可通过 Mock Connector 进入真实队列、按产品写入 PostgreSQL/PostGIS 并经授权 API 查询；任务、进度、计划和观测按产品隔离，产品注册表支持依赖队列；尚未注册产品仍会在界面禁用且 API 拒绝创建任务。不再将 Worker 与查询视为互不相连的演示。默认固定演示模式；管理员显式切入库模式后不做自动回退。

开发 API 内嵌执行器只用于单进程文件模式；独立 Worker 必须使用 PostgreSQL。水位线是当前配置来源的最新成功小时，不是全时段完整性保证；补数任务进度显示已提交小时。天擎适配代码已具备，真实鉴权、分页/截断分段、单位、质量码和现场网络仍需客户环境确认。
