# 采集与查询闭环验收记录

日期：2026-11-09（Asia/Shanghai），版本0.3.0。用户明确允许真实天擎暂缓，先实现功能。界面只参考新电子沙盘，入口复用“系统管理 → 站点数据”。

## 实现范围

- 按会话租户与授权场景创建手动/补数任务；时区整点校验、含首尾最多168小时、20个待完成任务上限、200条历史及去重。
- 逐小时提交观测和进度；当前小时失败后5秒/10秒退避，连续3次失败保留在失败队列，可重试/取消。水位线是最近成功小时，不承诺此前全时段无缺口。
- 每小时计划显式启停；重启后依据持久计划推进，最多自动追补24小时。任务取消与提交共用事务/锁；租约过期后恢复未完成小时，过期令牌不能回写。
- PostgreSQL/PostGIS：观测增加scene维度主键；队列状态独立表；行锁/SKIP LOCKED及数据库时钟控制领取，观测与任务进度同事务。支持多个独立Worker。
- 开发文件模式：单API进程嵌入执行器，共享串行文件仓库，重启后状态恢复；不支持多进程共享文件仓库。每地区最多1000个观测时次。
- 查询：固定演示和入库模式显式切换。入库时间轴、气象图层、摘要与趋势使用授权作用域的入库观测；指定时次缺数返回404，不重新生成。独立预览不受地图模式影响。
- UI：任务进度、水位、定时计划、补数、失败重试与取消、入库预览；北京时间显示；新资料自动刷新，保留用户按时间戳选择的时次；接口短暂失败后自动恢复。

## 审查与边界修正

审查发现定时计划的数据库时钟与进程时间混用、手动重试绕过队列上限，两项均用失败测试复现后修正。复审发现时间轴接口失败后不重试，用浏览器503测试复现后修正：只在完整时次刷新成功后确认版本，并在初始/后续失败时自动重试；慢请求执行期间不被五秒轮询反复取消，六秒延迟测试已覆盖。

浏览器验证还确认：补入更早资料会改变原数组下标，导致所选时次跳转。已先复现，再改为按时间戳保留选择。

## 仍不包括

真实天擎鉴权、分页、产品与字段/单位/质量映射尚未配置；未尝试真实联网。当前只有Mock地面观测产品，预留SceneConnector，不把外部接口假设写成已实现能力。

尚无多产品依赖图、批量高吞吐入库、完整连续缺测检测、独立指标/心跳告警、数据保留维护策略及大规模性能基线。Worker停机时任务保留待恢复；运行中任务在租约过期且执行器重新扫描后恢复，不据此声称源实时可用。文件模式用于本机演示，不能部署多个API写同一文件。

容器测试的PostGIS为amd64模拟，配置与迁移复制入测试卷以绕过本机Docker共享目录问题；目标机原生架构、实际bind mount、断公网、升级回滚与现场安全验收仍待验证。生产启动保护保留。
