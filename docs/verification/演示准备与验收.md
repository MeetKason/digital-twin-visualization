# 演示准备与验收

## 本轮范围（2026-11-11）

优先消除演示中断，补齐开场可用的书签、漫游路线，恢复 Ant 组件迁移后的整条浏览器回归。本轮仅本地开发和验证，未部署服务器。

- 受保护 API 的 401 统一使工作台退出到登录页，取消在途请求并阻止后续轮询；403 保留在原页处理权限错误。重新登录开启新会话，旧请求迟到的 401 不影响新会话。
- 正式账号登录后重新读取服务端已保存资料。未保存的编辑内容不会自动补交，避免跨账号写入。
- 仅隔离演示租户、无已保存资料的场景提供三个站点视角和两条三点路线。路线名称带 Mock；不改正式账号基线、不覆盖已有资料。首次保存仍沿用服务端修订校验。新演示登录生成独立租户，不能用它代替正式账号的跨登录持久化验收。
- 滑块手柄具备中文可访问名称，支持键盘操作；表格、选择框、上传使用 Ant 的实际交互做回归。

## 推荐演示顺序

1. 登录进入总览：展示西安行政边界、卫星影像和真实地形；检查现场地图网络和授权。内网无外网时应预先配置内网地图资源。
2. 搜索站点，打开并拖动详情，按时次查看 Mock 温度、降水。
3. 工具箱保存/调用视角，使用测距、测面和坐标定位。
4. 路径漫游选择 `Mock · 西安站点巡检`，展示三点序列、播放、暂停、停止；编辑保存后刷新验证。
5. 点位管理录入测试站点；上传客户允许演示的模型、PDF、视频并绑定站点。新演示登录已预置自有观测塔模型、3秒 Mock 视频和中文 PDF，并绑定首站；也可上传客户允许演示的资料。
6. 气象专题切换暴雨、强对流、低温、地质灾害，确认表格和地图时次一致，说明阈值结果是 Mock。
7. 设备监控展示在线、离线和告警遥测；系统管理展示 Mock 补数、执行状态、入库预览，再返回地图查看入库时次。
8. 使用正式测试管理员演示账号配置、审计和发布审批。演示租户不能管理真实账号。

## 演示门槛

- 1920×1080 和 1366×768 下主要操作、弹框、表头和滚动区可见。
- 自动化通过：`npm run check`、`npm run test:e2e`；记录真实运行结果，不以局部通过代替全量。
- 现场另做30分钟连续操作，包括快速切换地区、时间轴、图层、暂停/恢复网络、会话失效重登；自动化短流程通过不能代替现场长时间稳定性验收。
- 演示资料与正式数据隔离，缺数不伪装为实况，已保存资料刷新后可读取。
