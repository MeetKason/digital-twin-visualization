## 实施决策

- 新建独立仓库，使用 feat/initial-platform 分支，不改动用户其他项目。没有旧主分支需要合并。
- 第三个演示地区选成都，后续可通过场景 JSON 替换。
- 默认使用 Cesium 自带离线 NaturalEarthII 低精度底图。Figma 卫星图片不代替动态地图；高分辨率内网底图需配置。
- 登录入口明确标为演示，不接收生产密码。API 拒绝以 production 模式启动；服务端生产权限与租户隔离尚未实现。
- 默认图层透明度仅作用于选中图层；抽屉收起保留会话状态；输入坐标为 EPSG:4326 经度,纬度。
