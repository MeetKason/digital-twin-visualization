# 服务端基础验收记录

版本 0.2.0，日期 2026-11-07（Asia/Shanghai）。界面来源仍仅为新电子沙盘。

## 本轮实现

- 服务器配置账号、scrypt 哈希、不透明随机会话；Cookie 为 HttpOnly/SameSite=Strict，支持注销/过期及密码变更后失效。
- 独立演示租户；服务器按租户、场景和角色校验，浏览器声明的租户不授予访问权。
- 业务状态迁移到服务器；开发文件仓库和 PostgreSQL JSONB 仓库共用契约，修订号 CAS 防止覆盖，写入与拒绝有审计。
- 真实账号初始化工具；浏览器串行保存、失败回退、冲突提示和显式旧资料迁移。owner 校验防止旧账号排队请求写入切换后的账号。
- PostgreSQL 迁移、Compose 核心 API 数据库接入、只读账号配置挂载、存储就绪检查与连接关闭。
- 业务契约拒绝重复 ID、悬空模型/视角/附件引用，以及非法已保存方案。

## 审查及修正

独立审查指出代理地址作为唯一限速键会使一个用户输错锁住其他账号。已先用失败测试复现，再改为“客户端地址＋账号”；单层 Nginx 覆盖转发头，API 显式信任一跳，相关单元与 HTTP 测试通过。没有审查遗留 minor 清单。

补充检查确认 Vite 工作区默认文件服务能读取服务端私有数据文件（HTTP 200），已新增失败测试后封锁 .data、账号配置和备份路径；大小写别名也被拒绝。服务器运行数据和账号目录均排除 Git 和 Docker 构建上下文。

## 不包含的验收

PostgreSQL 新业务仓库验证不等于 PostGIS 观测链路或目标机验证。完整 Compose 镜像构建/运行、数据库备份恢复、离线升级回滚与目标架构尚未验收。

模型/视频/PDF 二进制仍在浏览器 IndexedDB，未完成服务器文件服务或完整跨租户文件隔离；界面演示用户配置也未变成真实账号管理控制台。真实天擎、地图、设备、算法、许可证与插件签名等缺口见架构完成度清单。生产启动保护继续启用，不能将本轮结果称为总体方案全部完成。

后续进展：2026-11-09 已续建服务器文件服务，旧二进制缺口的当前状态见 [服务端文件验收记录](服务端文件验收记录.md)。本文件保留 2026-11-07 的历史验收范围。
