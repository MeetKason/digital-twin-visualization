# 新电子沙盘菜单功能验收记录

设计来源：仅 Figma Page「新电子沙盘」1393:37400。用户明确排除其余 Page；当前画板索引也已删除其他 Page 的章节。

## 本次实现顺序

1. 总览地图：工具箱、测距测面、坐标拾取和定位、视角保存恢复、互斥雨雪雾视觉模拟；补齐设计中的基础与站点图层目录，无授权数据源的图层保留明确未接入原因。
2. 路径漫游：方案库、点位编辑/排序、地图或站点选点、模型与书签绑定、环绕和转场参数、路线及节点显示、开始/暂停/继续/停止。
3. 点位管理：目录/分类/检索、录入与修改、CSV 导入预校验/确认和导出、三维模型与默认巡航视角、视频/PDF 关联、摘要和趋势。
4. 气象专题：四个逻辑专题，地图/站点/观测指标/列表联动。设计中的重复“山洪地质灾害”条目合并为同一专题；不编造正式风险范围或预警。
5. 设备监控：该 Page 只有菜单而无独立设备画板；当前页展示“设备数据源未接入”，并可刷新真实本机 API 健康状态。
6. 系统管理：使用现有管理目录，提供本地演示用户/角色/状态维护、部署配置查看/导出和本地资料概览/导出。

## 自动验证

- 23 项单元/契约测试：原 SDK/API/Worker、坐标/地理计算、点位/CSV/方案、损坏及跨地区存储、CSV 公式防护、GLB/GLTF 外联资源拦截、异步资源清理。
- 7 条浏览器流程：原地图链路、API 错误、独立插件、菜单串联与刷新恢复、切换方案取消旧选点、地图测量和坐标校验、模型上传/真实预览/引用保护/地区隔离。
- TypeScript strict、ESLint、前后端生产构建、构建后 API 冒烟、Compose 配置检查。
- 全量依赖审计仍为 0 项已知漏洞；未新增运行依赖。

## 独立审查与修正

独立审查发现两项 P2：选点未完成时切换方案会写入旧方案；延迟模型预览在弹窗关闭后仍创建资源。已先补失败测试，再修复：切换/新建/删除取消选点，并以当前方案 ID 拦截旧回调；预览通过异步资源所有者管理，关闭或替换后释放模型和 Blob URL。没有审查遗留 minor 清单。

补充回归发现编辑点位重建地图会丢失开启的图层；现改为保持 Viewer，只刷新受影响的图层。浏览器测试覆盖该行为。模型弹窗使用独立三维预览区，避免被站点管理页面遮挡。

## 明确边界

新增业务资料按地区存于当前浏览器 localStorage，文件存于 IndexedDB；页面刷新可恢复，但换浏览器或清理存储不会保留。资料导出仅含元数据，不含模型/视频/PDF 二进制。

全部新增账号和业务数据为演示。没有声称完成服务端身份/权限校验、正式天擎、设备协议、风险算法、附件服务或多人共享数据。地图仍使用本地低精度底图，未接入内网天地图与正式地形。测量为球面近似；椭球地形高程不是实测资料。

Docker daemon 不可用，未执行容器、实机 PostgreSQL、目标架构镜像、恢复和现场断网验收。此记录不替代生产验收。
