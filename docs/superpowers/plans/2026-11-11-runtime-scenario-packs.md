# 运行时场景包实施计划

用户已要求按既定缺口表继续实现，本轮直接在现有工程推进，不部署或推送。

1. 场景包契约：格式/SDK版本、场景基础信息、菜单白名单、图层白名单、主题色和布局尺寸。总览与系统管理保留；基础图层、站点和温度时次依赖保留。拒绝脚本、任意资源URL和重复项。
2. 配置仓库：文件与PostgreSQL均提供租户隔离的CAS配置记录及同事务审计；新007迁移。与业务修订分开，不修改已有站点/观测。
3. 场景目录：内置JSON作为默认值，运行时发布包覆盖当前租户相应地区；草稿不对普通查询生效。发布快照保留20版，历史恢复为新草稿后再发布。
4. API：管理员导入/保存草稿、发布、恢复；授权用户读取生效配置。服务端校验禁用图层，账号地区授权仍独立执行。
5. 动态地区：允许配置账号地区ID，Mock Worker按任务的租户读取发布场景；不修改真实天擎地区连接配置，不将地理调整套用到旧观测。
6. 前端：系统管理增加Ant场景包管理表单、JSON导入/导出、版本列表。生效配置用于导航、图层、主题和布局，发布后重读目录；不运行包中任何代码。
7. 验证：先测试草稿/发布/冲突/隔离/恶意输入，再实现；执行npm run check、npm run test:postgres及浏览器全流程回归。更新中文README和实施状态。

实施状态：以上7项已完成。`npm run check`（30文件、91项）、`npm run test:postgres`、`npm run test:e2e`（25项）全部通过；场景管理宽屏/窄屏与发布后布局已检查。补充修复文件仓库按需读取及缺包隔离、Ant复选框/单选框公共样式冲突。本轮未部署、未推送，后续升级需007迁移与Web/API/Worker同步更新。
