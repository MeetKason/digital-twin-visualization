# Digital Twin Visualization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 建立独立、可运行、可扩展的数字孪生可视化系统首期工程。
**Architecture:** npm workspaces 管理 Web、API、Worker、契约和 SDK。Web 使用真正的 Cesium 地球与本地示例数据，API 提供演示契约，生产地图和真实采集通过配置接入。
**Tech Stack:** React/TypeScript, Vite, Cesium, NestJS, PostgreSQL/PostGIS, Vitest, Playwright。
**Spec:** docs/superpowers/specs/2026-11-07-platform-design.md（用户已在聊天批准推荐路径）。

## Global Constraints

- 中文名数字孪生可视化系统；英文名 Digital Twin Visualization；目录 digital-twin-visualization。
- 不使用 Cesium ion、公网 CDN、前端凭据；演示数据明确标记。
- 按 Figma 登录页和工作台实施；不将地图截图冒充交互地图。
- 真实天擎、权限矩阵和离线现场验收需要客户环境，不能以本机 Mock 替代。

## Review Focus

- 快速图层切换不得留下旧对象；SDK 异步加载测试覆盖。
- 场景切换不得保留错误地区的站点；浏览器验证覆盖。
- 无数据时次不得显示为当前实况；API 测试覆盖。
- 无底图配置仍能打开本地示例且明确提示；浏览器网络检查覆盖。
- 插件卸载不得留注册项；SDK 测试覆盖。
