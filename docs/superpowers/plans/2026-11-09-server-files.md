# 服务端模型和附件续建

范围：仅新电子沙盘现有模型、视频、PDF 的存储链路，不扩展页面设计。

- [x] 真实 HTTP 回归：上传/读取、租户/场景/角色/来源隔离、引用保护、重启恢复、无效文件拒绝。
- [x] 受控文件目录：随机标识、原子落盘、流式大小限制、内容检查、失败清理；文件操作审计。
- [x] 业务保存验证服务器资源引用；同场景串行保存/删除防止并发悬空引用。
- [x] 前端切换服务器文件 API，保留旧浏览器读取与显式迁移，删除先保存元数据。
- [x] Compose 持久卷、Nginx 上传限制、数据库和文件一致性备份/恢复说明。
- [x] 类型/lint/单元与 HTTP/浏览器/构建验证，独立审查并更新交付包。

约束：文件卷与数据库均需备份；当前仅单 API 实例，跨实例锁/对象存储/病毒扫描仍是生产验收缺口。旧 IndexedDB 文件不会静默上传或删除。
