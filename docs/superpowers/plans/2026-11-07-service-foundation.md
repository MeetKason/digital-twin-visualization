# 服务端业务与身份边界实施计划

用户要求按总体架构继续执行；本轮直接实现可独立验证的服务端基础，不等待现场天擎资料。

1. [x] 受控身份：服务器配置账号、scrypt 密码验证、不透明 HttpOnly 会话、注销/过期、登录限速；开发演示租户隔离，生产关闭演示入口。
2. [x] 数据隔离：所有场景、图层、数据和业务状态由服务端按会话租户/场景授权；只读角色不能写，管理字段仅管理员修改；写入有审计。
3. [x] 持久化：开发文件仓库用于无需 Docker 的本机验证，生产 PostgreSQL JSONB 仓库与迁移；业务状态带修订号，CAS 防止静默覆盖。
4. [x] 前端接入：真实账号入口与演示入口并存；站点/方案/书签等状态通过 API 保存与恢复，不再用 localStorage 当共享存储。冲突和失败明确提示。
5. [x] 真实 HTTP 集成测试验证账号、角色、跨租户/跨场景、重启恢复、并发冲突、无认证拒绝；原菜单交互回归、构建与独立审查。

边界：附件二进制仍暂存浏览器 IndexedDB，真实天擎、设备与局方地图不伪造；本轮不据此声称生产全部完成。真实 PostgreSQL、离线镜像与恢复实机测试依赖环境，保留未验收项。

本轮已额外启动 Docker，使用独立 PostgreSQL 16 容器验证新仓库；并未据此完成 PostGIS/完整 Compose/离线现场验收。参见 docs/verification/服务端基础验收记录.md 与 docs/architecture/架构完成度与待办.md。
