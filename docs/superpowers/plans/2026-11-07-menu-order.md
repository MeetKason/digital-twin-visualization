# 新电子沙盘按菜单实施计划

> 使用 executing-plans 在当前会话连续执行；用户已明确要求只参考新电子沙盘并按菜单逐个实现，无额外设计审批。

**Goal:** 将已搭建工程中的菜单从范围占位入口推进为可交互的本地演示业务。
**Architecture:** 沿用 React/Cesium/Nest；所有新增相机与测量能力通过 SDK 暴露。演示业务按地区版本化持久保存于浏览器，文件保存于 IndexedDB；生产账号/数据接入不冒充已完成。
**Spec:** 用户最新指令优先；Figma 文件仅 1393:37400 新电子沙盘可作为界面/功能依据。其他 Page 一律不参考。

## 顺序及验收

1. [x] 总览地图：工具箱控制、距离/面积/坐标拾取、坐标定位、保存与恢复视角、互斥雨雪雾；图层目录和异常状态。测试坐标/几何计算与测量取消、视角持久保存。
2. [x] 路径漫游：方案库、新建/编辑/保存、节点添加排序删除、节点参数、模型/视角绑定、启动/暂停/继续/停止。测试方案独立性与保存前禁止播放、卸载停止。
3. [x] 点位管理：目录搜索分类、录入与编辑、模板/导入/错误行、模型/默认视角、视频/文档关联、观测与趋势。测试重复编码、非法坐标、地区隔离和刷新恢复。
4. [x] 气象专题：按设计专题切换、地图/指标/重点站点与列表联动，全部标记 Mock，不构造正式风险结论。
5. [x] 设备监控：新电子沙盘仅有菜单，无独立设备画板；保持明确“未接入”状态，仅显示可核验的本机 API 健康与数据来源，不从其他设计页补造功能。
6. [x] 系统管理：依照新电子沙盘现有管理目录，提供演示用户/权限配置与部署配置查看；不将本地配置伪装为服务端权限 enforcement。
7. [x] 严格类型、lint、测试、构建、浏览器检查、独立审查和 README/交付包更新。

## Review Focus

- 测量取消、离开菜单与切换场景清理相机动画和实体。
- 文件、站点、方案和书签按场景隔离，引用删除受检查。
- CSV 模板安全转义、逐行校验、重复默认跳过。
- 敏感连接/密码不写入浏览器；示例用户配置仅为演示。
- 设备监控没有独立设计，不能声称已还原不存在的画板。
