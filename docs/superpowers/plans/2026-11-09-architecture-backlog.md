# 架构待办执行计划

**目标：** 完成本地 Mock 范围内性能基线、采集健康告警、插件发现校验、关系化业务与发布、离线包和升级回滚验证。

**方案：** 小步增量实现；保留服务器会话/租户授权和旧业务 JSONB；所有插件同源及哈希验证；离线发布使用版本标签与成套备份。

**技术：** React/TypeScript、NestJS、PostgreSQL/PostGIS、Playwright、Docker Compose。

**设计：** `docs/superpowers/specs/2026-11-09-architecture-backlog-design.md`

## 全局约束

- 不接入真实天擎，不添加虚构实时数据；Mock 数据显式标记。
- 不信任客户端租户身份；场景写入仍检查角色、来源、owner、revision。
- Cesium Viewer 仍只在 `apps/web/src/MapView.tsx`；不添加 CDN/ion/远程插件。
- 关系表不得破坏现存 `scene_business`；迁移需幂等、事务化、可回填。
- 离线包不得包含 `.env`、账号文件或生产凭据；升级前备份、回滚需数据库与文件成套恢复。

## 任务

1. **性能基线**：在 `scripts/` 增加 Playwright 测量脚本及 `npm run perf:baseline`；测地图首屏、一次图层加载、模型上传/预览；至少 5 次样本，输出环境、原始采样和 p50/p95 JSON/Markdown。用小型固定 GLB，不触碰用户数据。
2. **采集健康/告警**：为租户场景计算队列积压、失败任务、过期运行租约、请求范围缺测小时和计划延迟；增加受场景授权的只读健康 API 与系统设置/采集面板提示。测试多租户隔离、无数据、缺测和已完成数据。
3. **插件发现/完整性**：定义清单契约与同源目录发现，构建时计算入口 SHA-256；加载前校验路径、ID、版本、哈希与 SDK 主版本；测试发现、安装、卸载、错误清单、被篡改入口及快速卸载清理。
4. **关系实体/发布**：新增幂等 PostgreSQL 迁移，回填站点、漫游方案、书签、模型资产；保存时在现有 CAS 事务中双写；增加只读关系查询和管理员发布/版本列表 API/UI；测试回填、冲突、租户/场景隔离、快照不可变及回滚迁移前备份指导。版本回滚已实现为将所选发布快照以 CAS 写成新草稿修订，历史发布不变，并同步关系投影及审计；激活/审批流程仍待完成。
5. **离线交付**：为 Compose 镜像加版本标签；创建安全的离线 release 打包、校验和验证、升级/回滚 runbook；禁止 `pull`，验证无秘密文件；用隔离 Compose 和已构建镜像完成 no-pull 健康验收。保留目标 CPU/现场网络仍需现场验证的明确边界。

## 总体验收

每项先添加能失败的自动化用例，再实现。最后运行 `npm run check`、`npm run test:e2e`、针对 PostgreSQL 的迁移/发布验证以及离线包完整性和 no-pull Compose 验收；检查归档不包含密钥、账号文件、运行数据或 node_modules。
