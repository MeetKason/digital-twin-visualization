# 天地图真实地形补充设计

## 目标

地图固定使用天地图卫星影像，并将天地图 `mapservice/swdx` 三维高程服务解码为 Cesium Terrain Provider。移除矢量底图、地形晕渲影像及其切换控件；地形垂直夸张设为 1.2 倍并启用光照。

## 非目标

- 不把天地图 `ter_w` 地形晕渲影像当作真实高程地形。
- 不在代码、前端静态配置、镜像或 Git 中保存 Cesium ion 访问令牌。
- 不在本次建设自托管地形瓦片服务器或准备离线高程数据。

## 方案

1. **天地图高程服务（本次采用）**：请求 `mapservice/swdx?T=elv_c`，在浏览器用 pako 解压瓦片，按天地图 Cesium 数据约定解析 150×150 int16/float32 样本并重采样为 64×64 高程网格。优点是复用现有天地图 Key 和服务；需要 Key 授权访问实际页面来源，并且高程访问需联网。
2. **Cesium ion 或内网地形（后备）**：没有可用天地图 Key 时保留原有 `terrainUrl` / Cesium ion 支持，适配其他地区或部署环境。

用户指定优先使用天地图 `mapservice/swdx` 解码为 Cesium Terrain Provider；实现采用 Cesium `CustomHeightmapTerrainProvider`，并复用受会话保护、禁止缓存的运行时配置接口下发的天地图 Key。该浏览器端 Key 会用于跨域影像和高程请求，因此须在天地图控制台限制并允许实际访问页面来源。Cesium ion 仅保留为无天地图 Key 时的可选后备。

## 行为与边界

- 默认影像层固定为天地图 `img_w`，保留天地图版权署名。
- 删除地图右下角的底图切换按钮及矢量/地形影像选项。
- 天地图高程瓦片解压、解码或请求失败时保留平滑椭球并显示可见错误/状态提示，不伪装为已加载真实地形。
- 地形初始化在后台进行且有 15 秒超时；地形请求失败不得阻断图层、测量和地图工具初始化。
- 气象格网、站点标记、测量图形和示例范围线贴合地形，避免真实地形遮挡。
- 没有天地图 Key 时继续支持通过 `terrainUrl` 为内网环境配置地形，或使用可选 Cesium ion 后备。
- 地形服务访问依赖浏览器网络和 Key 来源授权；无可用地形服务时显示平滑椭球并提示未加载。

## 验收

- 地图只显示卫星底图，不出现矢量/地形切换控件。
- 有效天地图 Key 和服务可用时，初始化 Cesium 天地图高程 Provider，地表高度和倾斜视角可见真实高程起伏；场景垂直夸张为 1.2 倍并启用光照。
- 无令牌或地形服务失败时地图仍可使用，界面明确显示真实地形未加载。
- `npm run typecheck` 和 `npm run build` 通过；令牌不出现在打包静态资源及 Git 跟踪文件中。
