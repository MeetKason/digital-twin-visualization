# Cesium 真实地形设计

## 目标

地图固定使用天地图卫星影像，并显示 Cesium World Terrain 的真实高程起伏。移除矢量底图、地形晕渲影像及其切换控件。

## 非目标

- 不把天地图 `ter_w` 地形晕渲影像当作真实高程地形。
- 不在代码、前端静态配置、镜像或 Git 中保存 Cesium ion 访问令牌。
- 不在本次建设自托管地形瓦片服务器或准备离线高程数据。

## 方案

1. **Cesium ion 在线地形（推荐）**：通过 CesiumJS `createWorldTerrainAsync` 加载 Cesium World Terrain。优点是无需本地地形数据维护；代价是需要互联网、Cesium ion 账号/令牌，并受账号配额及使用条款约束。
2. **自托管地形瓦片**：用 `CesiumTerrainProvider.fromUrl` 指向组织内地形服务。优点是可在内网控制可用性与访问；代价是需准备授权高程数据、部署瓦片服务并维护容量。

本设计选择方案 1，依据用户指定使用 Cesium 真实地形。访问令牌使用最小权限并限制允许的站点来源；运行时从受会话保护、禁止缓存的 API 配置接口提供给地图，前端只用于 Cesium 请求。令牌不得写入仓库或公开配置文件。Nginx 对跨站 HTTPS 请求发送来源站点 Origin，以便 ion 检查受限令牌的授权来源。

## 行为与边界

- 默认影像层固定为天地图 `img_w`，保留天地图版权署名。
- 删除地图右下角的底图切换按钮及矢量/地形影像选项。
- Cesium World Terrain 加载失败时保留平滑椭球并显示可见错误/状态提示，不伪装为已加载真实地形。
- 地形初始化在后台进行且有 15 秒超时；地形请求失败不得阻断图层、测量和地图工具初始化。
- 气象格网、站点标记、测量图形和示例范围线贴合地形，避免真实地形遮挡。
- 继续支持通过 `terrainUrl` 为内网环境配置自托管 Cesium 地形服务；配置 URL 时优先使用该服务。
- 部署需配置 Cesium ion 令牌并允许浏览器访问 Cesium ion 地形服务。没有令牌时不访问 ion，地图显示平滑椭球并提示缺少配置。

## 验收

- 地图只显示卫星底图，不出现矢量/地形切换控件。
- 有有效令牌时，初始化 Cesium World Terrain，地表高度和倾斜视角可见真实高程起伏。
- 无令牌或地形服务失败时地图仍可使用，界面明确显示真实地形未加载。
- `npm run typecheck` 和 `npm run build` 通过；令牌不出现在打包静态资源及 Git 跟踪文件中。
