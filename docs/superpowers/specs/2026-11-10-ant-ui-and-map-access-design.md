# Ant Design 控件统一与地图服务恢复

## 目标

统一系统交互控件，优先复用已安装的 Ant Design 组件，并恢复服务器上天地图影像和地形瓦片。当前地图页面显示空白地球和瓦片失败提示；浏览器探测显示该 Key 来自另一应用且 IP 来源被天地图拒绝。截图中的气象系统应用 Key 在浏览器来源验证中能正常返回影像与 `swdx` 高程数据。

## 范围

- 工作台、登录、图层、时间轴、点位、漫游、地图工具、模型、资料维护及后台的按钮、文本输入、选择、滑块和文件上传统一使用 Ant Design 或基于其封装的组件。
- 复用 Ant Design `Button`、`Input`、`Select`、`Slider`、`Upload`、`Card`、`List`、`Table`、`Form` 等；仅地图画布、站点标记和布局专用容器保留自定义实现。
- 将正确的浏览器端天地图 Key 配置在服务器私密环境文件，绝不提交到代码库、日志或 README；保持 Key 类型和页面域名限制。
- 更新地图加载错误提示与降级行为，保证瓦片暂时不可用时地图仍可操作，并说明需要授权的页面来源。
- README 增加组件复用规则、地图 Key 配置和故障排查说明。

## 方案

1. 继续逐页手写控件：改动小但重复样式和行为继续漂移。
2. 在现有 Ant Design 上建立少量兼容封装，并逐页迁移通用控件；复杂地图专用控件保留自定义布局。此方案复用率高，且能维持现有 Figma 风格，故采用。
3. 全部改成 Ant Design 默认页面：统一速度快，但会覆盖现有沙盘视觉和地图专用交互，因此不采用。

## 实施边界

不调整业务权限、API 数据结构、数据库和地图服务商。项目工作台继续以天地图为主；授权失败时显示本地低精度底图和可恢复提示。浏览器 Key 仍由已登录 API 运行时下发。
