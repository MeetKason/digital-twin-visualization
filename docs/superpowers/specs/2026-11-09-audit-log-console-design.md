# 操作审计只读控制台

## 目标

在“系统管理”中提供租户管理员可用的操作审计页面，便于查看服务端已记录的登录、账号和业务操作。现有 `GET /api/audit` 已限制管理员并按当前会话租户查询，继续复用该 API。

## 范围与约束

- 新增审计菜单与页面，展示时间、操作人、场景、动作和结果。
- 支持关键词和结果筛选、刷新、CSV 导出；页面仅处理 API 返回的当前租户记录。
- 演示管理员读取其隔离演示租户的日志；非管理员继续显示服务端拒绝信息。
- 不新增审计事件、不改数据存储、不提供编辑或删除，不显示凭据或哈希。

## 方案

- 复用现有管理员 API：不改后端接口，减少权限面和重复逻辑。
- 新建一个全局审计表：会扩大跨租户数据暴露面且与现有 API 的租户范围不符，舍弃。

采用第一种方案。时间按本地时区显示；CSV 对单元格进行转义，输出当前筛选结果。
