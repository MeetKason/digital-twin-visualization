# 插件扩展与租户产品授权设计

按用户要求直接执行，沿用既有 React/Ant、NestJS、SDK、签名沙箱和配置CAS仓库，不部署、不推送。

## 方案与边界

插件沿用受控ESM与无网络opaque iframe，采用声明式菜单页面/Widget和异步站点Provider消息桥；宿主用Ant渲染描述，不接收HTML或React执行代码。相较同源加载，可保留现有隔离；不引入远程微前端运行时。Provider可使用宿主授权数据读取桥，不能自行访问内网接口。独立后端扩展作为模板通过服务端配置与宿主鉴权接口读取授权资料，令牌仅在服务环境中。

授权采用Ed25519离线签名许可证。在线自助发证需外部运营服务，目前没有此基础；仅存可编辑套餐开关会允许租户自我提权。签名覆盖租户、客户/项目、套餐、模块、数据集、地区、有效期、账号上限。授权服务读取可信公钥，私钥仅由离线签发工具读取，不放仓库或服务器。生产默认强制许可证；开发/隔离演示显式标识宽松模式。平台管理员从服务端PLATFORM_ADMIN_IDS配置，租户管理员只管理本租户且不能授予超出自身地区的权限。

## 行为

- 地图和基本站点/地面小时数据为基础依赖；附加模块和产品按许可证、已安装模块、场景启用、角色、区域取交集。关键API与Worker均执行校验。
- 许可证导入/吊销带CAS和审计；错误签名、错租户、过期、未生效、吊销均不能获得产品。吊销后旧证不能重新导入，续期需更新issuedAt和licenseId。
- 未授权业务集合不返回，提交时禁止修改隐藏集合并保留原始内容，避免前端保存误删。管理员仍可查看授权状态并由平台管理员修复许可证。
- 插件注册项带插件命名空间与所有权；卸载/启动失败/场景切换时清理全部注册、在途Provider查询与计时器。数据返回校验坐标、时次、来源和数量，不静默替换失败结果。
- 新增Ant授权管理界面、独立扩展模板、中文维护文档。真实天擎和设备接入仍后置。

## 验收

签名篡改/信任根/时间/吊销/续期/CAS/跨租户/越权账号分配、直接API绕过、业务隐藏字段保护、Worker拒绝授权外产品；插件注册归属、恶意描述/数据、Provider超时取消、启动失败清理及浏览器安装/页面/Widget/地图数据/卸载。执行check、PostgreSQL和全量浏览器回归。
